# MentoNexa

### Your Skills. Your Network. Your Future.

MentoNexa is a mentorship and professional networking platform designed to connect skilled refugees with mentors, professional networks, work experience, and career development opportunities.

## Key Features

- Professional mentor directory
- Mentorship request form
- Mentor selection
- Administrator login
- Admin dashboard
- Approve, reject, and delete requests
- Request statistics
- Mobile-responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Purpose

MentoNexa aims to help skilled refugees build professional connections, develop their careers, and explore employment opportunities.

## Project Status

ILO Mini-Hackathon demonstration project.

## Note

This is a front-end demonstration. Requests are stored locally in the visitor's browser.
